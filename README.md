# PDF Resume GitHub Pages Site

本项目不重新排版简历，而是直接在网页中展示原始 PDF，因此可以 100% 保留 LaTeX 输出格式。

## 部署步骤

1. 创建 GitHub 仓库（例如 `resume`）
2. 上传全部文件
3. 打开 Settings -> Pages
4. Source 选择 `Deploy from a branch`
5. Branch 选择 `main`
6. 等待 1-2 分钟

访问地址：

`https://你的用户名.github.io/resume/`

## 更新简历
